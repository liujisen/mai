## 🎯 当前配置

**筛选条件**（v4.0）：
```
最近3天 + (放量启动 或 底背离) + EMA6在EMA18上方
```

- 📅 **时间范围**：最近3天
- 🎲 **信号组合**：放量启动 或 底背离（满足任意一个）
- 📈 **趋势要求**：EMA6 > EMA18（上升趋势）
- 🌐 **股票池**：全部A股 5477只（主板+创业板+科创板）
