📊 效果说明
--------------------------------------------------------------------------------
✅ 保留功能:
  - 排除ST股（继续生效）
  - OBV能量潮分析
  - 量比分析
  - 技术信号筛选
  - 多进程并行优化

✅ 移除限制:
  - 不再限制最低价格（允许低价股）
  - 不再限制最高价格（允许高价股）
  - 不再限制最小市值（允许小盘股）
  - 不再限制最大市值（允许超大盘股）

💡 预期影响
--------------------------------------------------------------------------------
1. 信号数量增加
   - 会包含更多小盘股（<30亿）
   - 会包含更多大盘股（>500亿）
   - 会包含低价股（<3元）和高价股（>200元）

2. 筛选速度
   - 基本面筛选仍然会获取市值数据（用于ST判断）
   - 但不会因为市值或价格范围而过滤股票
   - 速度影响很小（约-5%）

3. 结果质量
   - 优点：更全面，不会遗漏好机会
   - 缺点：需要手动过滤垃圾股和微盘股
   - 建议：人工复盘时注意市值和价格

⚠️ 注意事项
--------------------------------------------------------------------------------
1. 低价股风险
   - 价格<3元的股票风险较高
   - 建议人工筛选时谨慎对待

2. 微盘股风险
   - 市值<30亿的股票流动性差
   - 容易出现操纵行为

3. 超大盘股特点
   - 市值>500亿的股票波动较小
   - 适合稳健投资者

4. ST股已排除
   - ST、*ST股票仍然会被自动排除
   - 这个保护机制保持不变

🚀 使用方法
--------------------------------------------------------------------------------
直接运行即可，配置已更新:

  python3 run_mai_enhanced.py

现在会扫描所有价格和市值范围的股票（除了ST股）

📋 如需恢复原限制
--------------------------------------------------------------------------------
如果想恢复原来的市值和价格限制，修改 run_mai_enhanced.py:

  fundamental_config = {
      'enable': True,
      'min_price': 3.0,           # 改回 3.0
      'max_price': 200.0,         # 改回 200.0
      'min_market_cap': 30e8,     # 改回 30亿
      'max_market_cap': 500e8,    # 改回 500亿
      'exclude_st': True,
  }
